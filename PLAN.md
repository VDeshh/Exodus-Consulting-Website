# Fennec Consulting - Landing Site Plan

## Goal
Static landing site driving visitors to book a Calendly meeting with Shiv or Vishal after seeing projects + services.

## Stack
- Single static site, no build step. Plain HTML + CSS (one `styles.css`) + tiny `script.js` for nav/scroll.
- Open `index.html` directly in browser or deploy to Netlify/Vercel/GitHub Pages.

## Brand / Colors (from fennecapp.com)
- Background: dark (`#0E0E10` / `#16161A`)
- Accent: gold `#E0B148`
- Text: light `#F5F5F5`, muted `#A0A0A8`
- Sans-serif, bold headings, card-based layout, modern minimal.

## Structure
**`index.html` (main page)** - single page, anchored sections:
1. **Hero** - "Fennec Consulting" + tagline: custom software + AI enablement to improve operational efficiency and grow revenue. Primary CTA: Book a call (Calendly).
2. **Services** - cards: Custom Software Projects, AI Enablement, Operational Efficiency, Revenue Growth.
3. **Projects** (main focus):
   - **Fennec** - modern OS for hospitality venues. Worked directly with owners; live in major Canadian venues: Harbour Event Centre, TradeX BC.
   - **Matchbox Global** - UK matchmaking software; building their tech.
4. **Experience** - AI enablement at Uniserve Communications Corporation (logo).
5. **CTA / Book** - embedded Calendly + emails.

**`about.html`** - Shiv Lohia + Vishal. UBC Computer Science + Master of Management grads. Tech consulting. Uniserve AI enablement experience + logo.
