Five tools or one system

What changes when the parts stop being separate

Most venues already own these jobs, spread across a ticketing platform, a spreadsheet, a till, a clipboard and an email tool. Nothing is missing. What is missing is one place where they agree. Each row below is an argument that a separate tool leaves running.

  1. 01

    The room and the booking disagree

    A host was double-booking tables over text message, so the room became software. Guests now book against the layout the night actually runs on.

  2. 02

    The same guest exists five times

    A ticket buyer, a guestlist name, a table booking, a loyalty record and a mailing list entry are one person. One profile carries the spend history instead of five exports.

  3. 03

    Two systems, one bar

    Menus, prices and packages push out of Fennec, closed tabs pull back in, and each object gets exactly one owner. That is the decision that prevents two prices for one bottle.

  4. 04

    Pours stop matching sales

    A monthly count finds a bad pour four weeks late. Reconciling poured against sold flags the overpour instead of absorbing it into the quarter.

  5. 05

    Nobody can explain the split

    A cruise operator could not explain a gratuity split, so the split became an engine. Palapa Tours Ottawa runs it standalone. Shipped
